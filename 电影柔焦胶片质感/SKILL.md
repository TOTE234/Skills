# 电影级画面描述生成器

> **核心原则：** 所有输出必须严格遵循五段式结构，【光影】部分须进行系统性细致刻画，全片统一电影柔焦胶片成像标准。

---

## 一、触发场景

本 skill 在以下场景中被激活：

- "描述一个电影画面" / "写一段镜头描述" / "分镜文案"
- "画面感写作" / "把这个场景画面化" / "电影质感描述"
- "光影设计" / "帮我设计这个镜头的光影"
- "蒙太奇分镜" / "多镜头描述" / "一组镜头"
- "shot description" / "cinematic scene" / "storyboard text"
- AI 绘图/视频生成的画面 prompt 撰写
- 影视前期分镜、剧本画面标注、视觉概念设计

---

## 二、输出结构（严格五段式）

**每一段必须以指定标题开头，段内为连续描述性文字，不得使用列表项。**

---

### 【主体及环境】

描述画面中出现的人物、物体、场景及其所处的物理环境。须涵盖：

- **人物**：身份、年龄感、穿着、姿态、表情、动作瞬间状态
- **核心物体**：与叙事直接相关的道具、物件及其状态
- **环境场景**：室内/室外、空间类型（街道、房间、自然景观等）、时代感、地域特征
- **环境细节**：天气、空气状态（湿度、雾气、尘埃）、背景中的生活痕迹（散落的物品、墙面的斑驳、地面的纹理）
- **氛围暗示**：通过环境细节暗示的时间段、季节、情绪基调

> 写作要求：从主体到环境逐层展开，主体描写须精确到可被视觉化还原的程度，环境描写须为光影和色调段落提供物理依据。

---

### 【构图与空间】

描述画面的构图方式与空间纵深关系。须涵盖：

- **景别**：远景 / 全景 / 中景 / 近景 / 特写 / 大特写（明确标注）
- **机位高度**：平视 / 俯拍 / 仰拍 / 鸟瞰 / 虫眼视角
- **构图法则**：三分法 / 中心对称 / 黄金螺旋 / 引导线构图 / 框架构图 / 对角线构图（选择并说明）
- **主体位置**：主体在画面中的位置及视觉权重
- **前景层次**：前景元素及其对画面深度的贡献（遮挡、虚实关系）
- **纵深结构**：前景—中景—背景的层次分布、空间透视感
- **留白与密度**：画面信息密度的疏密分布及视觉呼吸感
- **运动方向暗示**：若为动态画面，描述运动趋势在构图中的方向性引导

> 写作要求：构图描述须具体到可指导机位架设和画面取景的程度，空间纵深须交代清楚前中后景的层次关系。

---

### 【光影】

**本段为重点刻画段落，须进行系统性、层次化的光影描写。**

**必须依次覆盖以下七个维度：**

#### 1. 光源类型
- 明确所有光源：自然光（日光、月光、天光）、人造光（钨丝灯、荧光灯、LED、烛火、霓虹）、混合光源
- 标注主光源与辅助光源的层级关系
- 如有反射光、环境 bounce 光，须说明来源

#### 2. 光线方向
- 明确主光源相对于主体/镜头的方向：顺光 / 侧光 / 逆光 / 侧逆光 / 顶光 / 底光
- 多光源时分别标注各自方向
- 方向对造型的影响：塑造体积感、扁平化、剪影化等

#### 3. 明暗过渡
- 描述亮部到暗部的过渡方式：硬边过渡（清晰明暗分界）/ 软边过渡（渐变过渡）
- 过渡区域的宽窄与位置
- 明暗反差比（高反差 / 低反差 / 中间调）
- 暗部是否保留细节（阴影区的可读性）

#### 4. 轮廓光
- 是否存在轮廓光（rim light / edge light）
- 轮廓光的光源方向与主体边缘的关系
- 轮廓光的宽度、强度、色温偏移
- 轮廓光对主体从背景中分离的贡献

#### 5. 漫射光
- 环境漫射光的来源与强度（天空漫射、墙壁 bounce、雾气散射）
- 漫射光对整体画面柔化的贡献
- 漫射光填充阴影的程度（阴影是否被环境光提亮）
- 漫射光的色温特征

#### 6. 丁达尔效应
- 是否存在丁达尔效应（光束穿透介质形成的可见光路）
- 触发条件：雾气、烟尘、水汽、窗帘缝隙等介质
- 光束的形态：平行光束、散射光锥、体积光的浓度梯度
- 光束在空间中的走向与画面构图的关系
- 若场景中不存在丁达尔效应的条件，明确说明"无丁达尔效应"并解释原因

#### 7. 光影情绪
- 光影整体传达的情绪：温暖/冷峻/神秘/压抑/空灵/日常感
- 光影与叙事主题的呼应关系

> 写作要求：七个维度须全部覆盖，不可遗漏。每个维度须结合具体场景的物理条件进行描写，而非泛泛而谈。光源、方向、过渡须精确到可指导灯光布置的程度。

> **详细光影术语参考：** 见 [`references/lighting-techniques.md`](references/lighting-techniques.md)

---

### 【色调】

描述画面的整体色彩倾向与色彩关系。须涵盖：

- **主色调**：画面的主导色相（暖橙、冷蓝、低饱和灰绿等）
- **色温**：整体偏暖 / 偏冷 / 中性，及具体色温估值范围（如 3200K 暖黄 / 5600K 日光 / 7500K 冷蓝）
- **饱和度**：高饱和 / 低饱和 / 去饱和倾向，及饱和度在不同区域的分布差异
- **对比色关系**：画面中存在的互补色或对比色对（如橙青对比、红绿对比）
- **肤色还原**：人物肤色的色相偏移（偏暖橘 / 偏中性 / 偏冷粉）及饱和度
- **暗部色偏**：阴影区域的色相倾向（偏蓝 / 偏绿 / 偏紫）
- **高光色偏**：亮部区域的色相倾向（偏暖黄 / 偏冷白）
- **整体调色风格**：类比已知电影调色风格（如 bleach bypass、teal & orange、muted earth tones、pastel desaturation）

> 写作要求：色调描述须具体到可指导后期调色的程度，色温、饱和度须给出方向性估值，不可仅用"好看""舒服"等主观词。

---

### 【摄影与成像】

**本段为固定标准，每次输出须原样呈现以下文字，不得修改、删减或添加：**

> 电影画面质感，轻微柔焦光效，高光、人物皮肤边缘自然柔和扩散；适度画质损失，削弱强烈数码锐度，细腻胶片颗粒，自然动态模糊，原生镜头成像质感，富有真实生活气息。

**若用户额外指定了镜头参数**（焦段、光圈、机型等），在上述固定文字之后另起一行补充：

- 镜头焦段（如 35mm / 50mm / 85mm）
- 光圈值（如 f/1.4 / f/2.8 / f/5.6）
- 特殊镜头特征（如变形宽银幕 anamorphic、微距、移轴）
- 感光介质（如 Kodak Vision3 500T 5219 胶片、Sony Venice 数码）

> 注意：固定标准文字必须完整保留，用户指定的镜头参数仅作为补充信息追加其后，不得替代或修改固定标准。

---

## 三、多镜头蒙太奇规则

当用户要求生成多镜头蒙太奇（如一组分镜、一个场景的多个机位）时：

### 3.1 结构统一

- 每个镜头独立使用完整的五段式结构输出
- 镜头之间以分隔线（`---`）和镜头编号标注分隔
- 格式示例：

```
## 镜头 01 — [镜头标识，如"全景·街道"]

【主体及环境】
...

【构图与空间】
...

【光影】
...

【色调】
...

【摄影与成像】
电影画面质感，轻微柔焦光效，高光、人物皮肤边缘自然柔和扩散；适度画质损失，削弱强烈数码锐度，细腻胶片颗粒，自然动态模糊，原生镜头成像质感，富有真实生活气息。

---

## 镜头 02 — [镜头标识]
...
```

### 3.2 视觉连贯性保障

- **色调一致**：同一场景的多个镜头须保持统一的色温和调色风格，仅允许因机位不同产生的细微变化
- **光源一致**：同一场景的光源设定（方向、类型、强度）在所有镜头中保持一致，不同机位仅改变光线与主体的相对关系
- **成像标准一致**：所有镜头的【摄影与成像】段落使用完全相同的固定标准文字
- **环境细节呼应**：前序镜头中出现的环境元素（如墙上的光斑、桌上的水杯）在后续镜头中须保持存在且状态连贯
- **时间连贯**：同一场景的镜头须处于同一时间段，光影的细微变化仅源于机位差异而非时间推移（除非用户明确要求时间流逝蒙太奇）

### 3.3 蒙太奇节奏

- 标注每个镜头的建议时长（如 3s / 5s / 8s）
- 在全部镜头输出后，附加一段【蒙太奇节奏说明】，描述镜头组接的节奏逻辑、转场方式（硬切 / 叠化 / 匹配剪辑）及情绪推进曲线

> **详细蒙太奇指南：** 见 [`references/montage-guide.md`](references/montage-guide.md)

---

## 四、输出规范

### 4.1 语言

- 默认使用用户输入的语言进行输出
- 若用户使用中文，所有段落描述使用中文
- 若用户使用英文，所有段落描述使用英文
- 段落标题【主体及环境】等始终使用中文方括号格式，无论输出语言

### 4.2 篇幅

- 单镜头描述：每个段落 3-6 句，【光影】段落可适当加长至 6-10 句
- 多镜头蒙太奇：每个镜头保持上述篇幅，避免镜头间篇幅差异过大

### 4.3 禁止事项

- 禁止使用列表项（bullet points）书写段落内容，所有段落须为连续描述性文字
- 禁止修改【摄影与成像】中的固定标准文字
- 禁止遗漏【光影】段落的七个维度中的任何一个
- 禁止使用"画面很美""光影动人"等空洞评价，所有描写须具体到可视觉化还原

### 4.4 工作流程

1. **解析用户输入**：提取场景主体、环境、情绪基调、镜头数量等关键信息
2. **构建光源逻辑**：根据场景环境推演出物理合理的光源设定
3. **逐段输出**：按五段式结构依次输出，【光影】段落须完整覆盖七个维度
4. **成像标准固定**：【摄影与成像】段落原样输出固定标准文字
5. **多镜头校验**（如适用）：检查色调、光源、成像标准在所有镜头中的一致性
6. **节奏说明**（如适用）：在蒙太奇结尾附加节奏说明
